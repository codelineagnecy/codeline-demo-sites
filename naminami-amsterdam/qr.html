Zo gebruik je hem

Eén kaart, elke tafel

  • Print op A6 of A5 en zet de kaart in een standaard op elke tafel.
  • Plak de code ook bij de kassa of op de gevel.
  • De QR-code verwijst naar de menukaart. Pas je de kaart aan, dan hoef je de code niet te vervangen.
  • Met een eigen domein werkt de code ook op je eigen adres, bijvoorbeeld naminami.nl/menu.
